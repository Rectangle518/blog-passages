# Reflexion: Language Agents with Verbal Reinforcement Learning

## 一、引言
   - **研究背景**：大语言模型（LLM）越来越多地被用作目标驱动的自主代理，与外部环境（游戏、编译器、API）交互，但传统强化学习方法需要大量训练样本和昂贵的模型微调
   - **核心问题**：语言代理如何快速、高效地从试错中学习，而不依赖梯度更新？
   - **研究动机**：人类通过反思先前失败来迭代学习复杂任务——Reflexion模拟这一过程
   - **⭐ 创新点**：提出Reflexion框架——通过**语言反馈（verbal reinforcement）**而非权重更新来强化语言代理
   - 主要贡献：
      1. 提出"语言强化"新范式，将策略参数化为代理记忆编码+LLM参数
      2. 实证表明LLM的自反思能力在少量试错中极为有效
      3. ⭐ 引入**LeetcodeHardGym**——包含40道LeetCode难题、19种编程语言的代码生成RL环境
      4. 在多个任务上超越强基线，取得SOTA结果

## 三、方法：Reflexion——通过语言反思进行强化
   ### 3.1 整体框架
   - 三个核心模型：Actor（$M_a$）、Evaluator（$M_e$）、Self-Reflection（$M_{sr}$）
   - 迭代优化流程：生成轨迹→评估→自反思→存入记忆→下一轮迭代
   ### 3.2 Actor（行动模型）
   - 基于LLM，根据状态观测生成文本和动作
   - 从策略 $\pi_\theta$ 中采样动作 $a_t$
   - 探索多种Actor模型：Chain-of-Thought、ReAct
   - 增加记忆组件 $mem$ 提供额外上下文
   ### 3.3 Evaluator（评估模型）
   - 输入生成的轨迹，计算奖励分数 $r_t = M_e(\tau_t)$
   - 多种评估策略：
      - 推理任务：精确匹配（EM）评分
      - 决策任务：预定义启发式函数
      - 编程任务：LLM自身作为评估器
   ### 3.4 ⭐ Self-Reflection（自反思模型）
   - 将稀疏奖励信号（如二值成功/失败）转化为具体的语言反馈
   - 分析轨迹和奖励，生成可操作的改进建议
   - 反馈比标量奖励更具信息量，存入长期记忆
   - **关键机制**：失败时推断具体错误动作→用语言表达应采取的替代动作→存储经验→后续试验利用
   ### 3.5 Memory（记忆系统）
   - **短期记忆**：轨迹历史（当前回合的细粒度细节）
   - **长期记忆**：自反思模型的输出（跨回合的蒸馏经验）
   - 实践中限制最大存储经验数 $\Omega$（通常1-3条），以适应LLM上下文长度
   ### 3.6 Reflexion过程（算法）
   1. 初始化Actor、Evaluator、Self-Reflection模型
   2. 生成初始轨迹 → 评估 → 生成自反思 → 存入记忆
   3. 迭代循环：生成轨迹→评估→自反思→追加记忆
   4. 终止条件：Evaluator判定通过或达到最大试验次数

## 四、实验
   - 三类任务：顺序决策（AlfWorld）、推理（HotPotQA）、编程（HumanEval/MBPP/LeetcodeHardGym）
   - ⭐ **关键结果总览**：AlfWorld提升22%、HotPotQA提升20%、HumanEval提升11%

   ### 4.1 顺序决策：AlfWorld
   - **任务**：134个文本环境，6类家庭任务（找物、移物、操作物等）
   - **基线**：ReAct
   - **自评估方法**：LLM自然语言分类 + 手写启发式（重复动作>3次或动作数>30则触发反思）
   - **⭐ 关键结果**：ReAct+Reflexion完成130/134任务（97%），12轮内持续学习
   - **分析**：
      - 基线主要错误：代理误以为拥有某物品，导致长轨迹无法回溯
      - Reflexion将失败轨迹蒸馏为相关经验，作为"自我提示"
      - 记忆帮助两种情况：(1) 识别早期错误并建议新计划 (2) 利用多轮经验彻底搜索房间
      - ReAct-only在22%幻觉率处收敛，无长期恢复迹象

   ### 4.2 推理：HotPotQA
   - **任务**：Wikipedia-based 113k问答对，需多文档推理
   - **设置**：
      - CoT + Reflexion（纯推理，提供GT上下文）
      - ReAct + Reflexion（推理+行动，使用Wikipedia API）
   - **评估**：精确匹配（EM），记忆大小3条经验
   - **⭐ 关键结果**：
      - Reflexion在所有基线上显著提升
      - 基线方法（ReAct-only、CoT-only）在后续试验中无法概率性改善
      - CoT(GT)+Reflexion：无GT答案仍提升14%准确率
   - **消融实验**：
      - 对比：CoT(GT)基线 → +情景记忆(EPM) → +自反思
      - ⭐ 自反思在情景记忆优势之上额外提升8%，证明反思引导的精炼优于单纯精炼

   ### 4.3 编程
   - **任务**：Python和Rust代码生成（MBPP、HumanEval、LeetcodeHardGym）
   - **自评估方法**：⭐ 自生成单元测试套件（CoT生成→AST过滤→采样最多6条测试）
   - **⭐ 关键结果**：

   | 基准+语言 | 前SOTA Pass@1 | Reflexion Pass@1 |
   |---|---|---|
   | HumanEval (PY) | 80.1 (GPT-4) | **91.0** |
   | HumanEval (RS) | 60.0 (GPT-4) | **68.0** |
   | MBPP (PY) | 80.1 (GPT-4) | 77.1 |
   | MBPP (RS) | 70.9 (GPT-4) | **75.4** |
   | Leetcode Hard (PY) | 7.5 (GPT-4) | **15.0** |

   - **分析**：
      - MBPP Python表现略差原因：假阳性测试执行率高达16.3%（vs HumanEval仅1.4%）
      - 假阴性优于假阳性：假阴性时代理可能通过反思识别错误测试并保留正确代码

## 一些通俗理解

想象一下你正在学做一道菜。第一次做糊了，你会想："哦，火太大了，下次关小一点。"第二次盐放多了，你又想："少放盐。"每做一次，你就总结经验，下次做得更好。

**Reflexion 就是让AI学会这种"复盘"的方法。**

### 以前AI是怎么学习的？

传统的强化学习，就像训狗——做对了给奖励，做错了给惩罚，然后通过大量重复训练来调整脑内的"权重参数"。这对AI来说既费钱又费时，因为每次都要重新微调那个庞大的模型。

### Reflexion 有什么不同？

Reflexion 的核心思路是：**不修改AI的"大脑"（权重），而是让AI用语言给自己写"错题本"。**

具体来说，它有三个角色配合工作：

1. **行动者**——干活的AI，负责在环境中做决策、写代码、回答问题
2. **评估者**——判卷的AI，判断干得好不好（成功/失败，或者打个分）
3. **自反思者**——最关键的角色，负责在失败后"复盘"，用自然语言写出：哪里做错了？下次该怎么改？

这些反思文字会被存进一个**记忆本**里。下次再遇到类似任务时，AI会翻看自己的错题本，避免重蹈覆辙。

### 一个具体例子

比如在编程任务中：

- **第一轮**：AI写了一段代码，运行后出错
- **反思**：AI写下"我忘记了处理空列表的情况，下次应该先加一个判断"
- **第二轮**：AI带着这条反思重新写代码，这次通过了

整个过程中，AI的模型参数没有任何修改，但它通过阅读自己写的经验总结，变得越来越靠谱。

### 效果有多好？

论文在三类任务上做了测试，结果非常亮眼：

- **家务决策任务**（AlfWorld）：从"经常迷糊"提升到97%的任务完成率，比基线高出22%
- **知识推理问答**（HotPotQA）：比基线提升20%，而且基线方法重试多少次都不会进步，Reflexion却能越试越准
- **编程写代码**（HumanEval）：在Python编程上达到91%的通过率，**超越了当时的GPT-4（80%）**

### 为什么这个方法聪明？

它有几个很妙的地方：

- **省钱省力**：不需要微调模型，只要在提示词里加上反思内容就行
- **反馈更丰富**：传统强化学习只给一个分数，Reflexion给的是具体的文字建议——"你这里逻辑错了"比"你得了0分"有用得多
- **可解释**：你能看到AI"在想什么"，知道它为什么改了某个决定
- **像人一样学习**：人类就是靠反思错误来进步的，而不是靠修改大脑神经元

### 局限性

- 如果任务需要"天马行空的创意"（比如在电商网站搜冷门商品），反思也帮不上忙——因为AI想不到新方向
- AI写的自我测试可能不准，测试写错了就会误导自己
- 自我纠正能力目前只有大模型才有，小模型"反省"不出来

简单来说，**Reflexion 就是给AI配了一个"错题本+复盘习惯"，让它不用修改自身参数，光靠"吃一堑长一智"就能越做越好。**
