## **宏观经济学（上集）知识点总结**

这个视频的核心思路是：从宏观经济学诞生的历史背景出发，沿着凯恩斯的理论逻辑链，逐步推导出整个宏观经济学的核心模型体系。以下是按照视频讲解顺序梳理的关键知识点。

### **一、宏观经济学的诞生背景**

- **1776年**，亚当·斯密发表《国富论》，标志着**微观经济学**诞生，亚当·斯密被称为微观经济学鼻祖。
- **1936年**，凯恩斯发表《就业、利息和货币通论》（简称《通论》），标志着**宏观经济学**诞生，凯恩斯被称为宏观经济学之父。
- 在这160年间，只有微观经济学，没有宏观经济学。
- **1929年经济大危机**是促使宏观经济学诞生的直接背景——微观经济学的"市场万能"理论无法解释大危机。

### **二、萨伊定律 vs 凯恩斯理论**

- **萨伊定律**（法国经济学家萨伊提出）：**供给决定需求**——有多少供给才有多少需求；如果供过于求，通过价格（看不见的手）调节，最终实现供求均衡。
- 凯恩斯反驳：**需求决定供给**，危机的真正原因在于**有效需求不足**。
  - "有效需求"即有支付能力的需求——想买但买不起，不构成有效需求。
  - 有效需求不足 → 产品卖不出去 → 库存积压/资源闲置 → 厂商减产 → 解雇工人 → 失业上升 → 收入下降 → 消费进一步减少 → 进一步减产……形成**恶性循环**，最终导致经济大危机。

### **三、有效需求不足的三大原因**

（凯恩斯三大心理规律）

1. **边际消费倾向递减**（$\Delta C / \Delta Y$ 递减）
   - 收入增加，但消费增加的比例在降低。例：月入1000时消费100（10%），月入2000时消费150（7.5%），比例在递减。
   - 后果：**消费需求不足**

2. **资本边际效率递减**
   - 资本家的投资预期在降低，简单来说就是不想投资了。
   - 后果：**投资需求不足**

3. **流动性偏好**
   - 人们偏好持有货币（现金），涉及货币需求（L）和货币供给（M）。
   - 后果：影响利率，进而影响投资

### **四、国民收入的构成**

（GDP = 四驾马车）

$$Y = C + I + G + (X - M)$$

- **C**：消费
- **I**：投资
- **G**：政府购买
- **X - M**：净出口（进出口）

考研和期末主要考查前三项（封闭经济模型），暂不考虑国际市场。

### **五、凯恩斯的政策主张**

由于 C（消费）和 I（投资）不足，要让 Y 增加，就需要 **G（政府购买）增加**。

传导机制：政府增加开支（如修桥）→ 雇佣工人 → 工人收入增加 → 消费增加 → 库存减少 → 厂商扩大投资 → 招聘更多工人 → 失业下降 → 收入增加 → 消费再增加 → 投资再增加……形成**良性循环**。

- **增加政府开支** = **扩张性财政政策**
- **减少政府开支** = **紧缩性财政政策**

### **六、消费函数**

凯恩斯消费函数：

$$C = \alpha + \beta Y$$

- $\alpha$：自发性消费（与收入无关的基本消费）
- $\beta$：边际消费倾向（MPC），$0 < \beta < 1$
- C 完全由 Y 决定

将消费函数代入国民收入方程 $Y = C + I + G$，得到：

$$Y = \frac{\alpha + I + G}{1 - \beta}$$

这就是**收入-支出模型**的核心方程。

### **七、投资函数**

凯恩斯认为投资与利率呈**反向变动**关系：

$$I = e - dr$$

- $e$：自主投资
- $d$：投资对利率的敏感度
- $r$：利率

逻辑：利率越高（如存款利率20%），人们越不愿意投资创业，宁愿把钱存银行；利率越低，则更倾向于拿出钱投资。

### **八、IS 曲线**

将消费函数和投资函数代入 $Y = C + I + G$：

$$Y = \frac{\alpha + e - dr + G}{1 - \beta}$$

整理后以利率 $r$ 为纵轴、收入 $Y$ 为横轴，得到**向右下方倾斜的 IS 曲线**，表示产品市场均衡。

- **扩张性财政政策**（G 增加）→ IS 曲线**右移**
- **紧缩性财政政策**（G 减少）→ IS 曲线**左移**

### **九、货币需求与 LM 曲线**

**凯恩斯的货币需求三动机：**

1. **交易动机**：日常消费需要持有现金 → 与**收入 Y** 正相关
2. **预防动机**：应对意外支出需要留现金 → 与**收入 Y** 正相关
3. **投机动机**：把握股市等投机机会需要备现金 → 与**利率 r** 负相关

货币需求函数：

$$L = kY - hr$$

- $kY$：交易动机和预防动机（与收入正相关）
- $hr$：投机动机（与利率负相关）

货币供给 $M$ 在一定时期内为常数。令 $L = M$（货币市场均衡）：

$$kY - hr = M$$

整理后得到 **LM 曲线**，表示货币市场均衡。

- **扩张性货币政策**（M 增加）→ LM 曲线**右移**
- **紧缩性货币政策**（M 减少）→ LM 曲线**左移**

### **十、IS-LM 模型**

将 IS 曲线和 LM 曲线放在同一坐标系（纵轴为利率 $r$，横轴为收入 $Y$），交点即为**产品市场与货币市场同时均衡**的状态。

### **十一、AD-AS 模型**

（总需求-总供给模型）

AD 曲线不是新知识点，而是由 IS-LM 模型推导而来。

关键步骤：将名义货币供给 $M$ 替换为实际货币供给 $M/P$（$P$ 为物价水平），则 LM 方程中引入了变量 $P$。令 IS 和 LM 联立，消去利率 $r$，即可得到 $Y$ 与 $P$ 之间的函数关系——这就是**AD 曲线**（向右下方倾斜）。

- **扩张性财政政策**或**扩张性货币政策** → AD 曲线**右移**
- **紧缩性财政政策**或**紧缩性货币政策** → AD 曲线**左移**

AS 曲线（总供给曲线）向右上方倾斜，与微观中的供给曲线方向一致，但反映的是全社会的总供给。

### **十二、菲利普斯曲线**

菲利普斯曲线也不是新知识点，而是由 AD-AS 模型推导而来。

- **通货膨胀率**与**失业率**呈**反向变动**关系（替代关系）
- 通胀率越高 → 失业率越低；通胀率越低 → 失业率越高

推导逻辑：扩张性政策 → AD 右移 → 价格上升（通胀率上升）+ 产出增加 → 就业增加 → 失业率下降。

### **整体框架的逻辑链**

整个宏观经济学的核心内容可以用一条推导链串联：

```
三大心理规律 → 有效需求不足 → 研究消费/投资/货币需求
    ↓
消费函数 + 投资函数 → IS曲线（产品市场）
货币需求函数 + 货币供给 → LM曲线（货币市场）
    ↓
IS-LM模型 → 引入物价P → AD-AS模型
    ↓
AD-AS模型 → 通胀与失业关系 → 菲利普斯曲线
```

视频的核心观点是：宏观经济学中看似复杂的概念（IS、LM、AD-AS、菲利普斯曲线），实际上都是**层层推导**的关系，没有一个真正"全新"的知识点——理解了前置逻辑，后面的内容自然水到渠成。

## **宏观经济学（下集）知识点总结**

这是视频的下半部分，核心内容围绕"凯恩斯理论的失灵"以及由此兴起的三大经济学流派展开，最后总结宏观经济理论及政策的演变。

### **一、物价与产出的四种组合及凯恩斯政策的失灵**

物价（P）与产出/国民收入（Y）之间存在四种组合情况：

| 情况 | 物价 | 产出 | 凯恩斯政策是否有效 |
|------|------|------|-------------------|
| 1 | 高 | 高 | 有效——紧缩政策降温 |
| 2 | 低 | 低 | 有效——扩张政策刺激 |
| 3 | 低 | 高 | 无需政策——天大的好事 |
| 4 | 高 | 低 | **失灵**——即"滞胀" |

前三种情况凯恩斯的需求管理政策都能应对，但第四种情况——**高物价+低产出**，即**滞胀（Stagflation）**——凯恩斯政策完全失灵：

- 如果用**扩张政策**：产出可能增加，但物价更高，通胀恶化
- 如果用**紧缩政策**：物价可能下降，但产出更低，经济更萧条

这种两难局面直接动摇了凯恩斯学派的统治地位。

### **二、滞胀的背景与影响**

- 二战后到70年代之前是凯恩斯学派的"黄金时期"，凯恩斯学派占据绝对主流地位。
- 70年代**滞胀**出现后，凯恩斯学派束手无策，其他学派趁机崛起，猛烈抨击凯恩斯主义。
- 初级宏观经济学中，主要考查三大反凯恩斯学派：**货币学派、理性预期学派、供给学派**。

### **三、货币学派（弗里德曼）**

**核心观点：**

1. **主张货币政策**为主（vs 凯恩斯主张财政政策为主），政府唯一的政策就是**控制货币供给**
2. **引入"预期"概念**——弗里德曼提出**附加预期的菲利普斯曲线**，指出凯恩斯学派忽视了一个关键因素：**公众的预期**

**货币幻觉 vs 公众预期：**

- 凯恩斯学派认为工人存在**货币幻觉**：工资从5000涨到8000，工人只看到名义工资涨了3000很高兴，却忽视了物价指数翻倍（从1变2），实际工资反而从5000降到了4000
- 弗里德曼反驳：**长期来看工人不是傻子**，工人会发现实际工资在下降，会通过工会要求涨工资
- 企业涨工资 → 成本上升 → 只能解雇工人 → 失业率重新上升

**短期菲利普斯曲线 vs 长期菲利普斯曲线：**

- 短期菲利普斯曲线：通胀率与失业率反向变动（凯恩斯学派观点）
- 长期菲利普斯曲线：变成一条**垂直线**——政府扩张政策在长期**只能造成通货膨胀**，不能降低失业率
- 滞胀的产生逻辑：公众本可以通过预期自动调整回充分就业状态，但政府中途介入干预（凯恩斯式的需求管理），反而打断了公众的调整过程，导致滞胀

### **四、理性预期学派（卢卡斯）**

**核心观点：**

1. 同样强调**预期**的作用，比货币学派更进一步
2. **卢卡斯批判**：批判凯恩斯学派的模型忽略了公众的理性预期

**AD-AS模型下的分析：**

- 凯恩斯学派中，AD曲线移动时AS曲线是**固定的**
- 卢卡斯认为，公众存在理性预期，价格变化时公众会调整预期，导致**AS曲线也会发生移动**（向左移动）
- 最终结果：AD右移 + AS左移 → 总产出不变，只剩物价上涨
- 结论：凯恩斯的扩张政策**不能使国民收入增加，只会造成通货膨胀**

### **五、供给学派**

**核心观点：**

1. 打出"**回到萨伊那里去**"的口号——供给决定需求，与凯恩斯的"需求决定供给"针锋相对
2. 但并非真的回到萨伊定律，只是表明与凯恩斯对立的决心
3. 最著名的政策主张：**减税**
4. 实践案例：80年代**里根减税**，美国经济出现一定效果
5. 争议：凯恩斯学派认为减税本身就是凯恩斯财政政策的一部分（减少税收 → 增加可支配收入 → 刺激需求 → Y增加），减税的功劳应归于凯恩斯主义

### **六、新凯恩斯学派的回应**

凯恩斯学派在滞胀后做出调整：

- **吸收了"预期"概念**——将其引入凯恩斯框架
- **保留了政府干预思想**——与货币学派、理性预期学派反对政府干预不同，新凯恩斯学派认为政府仍然需要干预经济

### **七、宏观经济理论及政策的演变**

这是考研常见的一道大题，视频给出了完整的答题脉络：

#### **1. 凯恩斯主义阶段（1929年后）**
- 1929年经济大危机，古典经济学/微观经济学束手无策
- 凯恩斯登场：**需求决定供给**，主张**需求管理**
- 运用财政政策与货币政策调节总需求
- 形成新古典综合派，IS-LM模型成为分析财政/货币政策效果的核心工具
- **相机抉择**：根据经济形势灵活调整政策（vs 货币学派的"单一规则"）
- **功能财政思想**：该赤字就赤字，该盈余就盈余，不追求年年收支平衡

#### **2. 滞胀时期（70年代）——凯恩斯失灵**
- 滞胀出现：高通胀+高失业并存，凯恩斯政策无法解决

#### **3. 货币主义学派（弗里德曼）**
- 猛烈抨击凯恩斯主义
- 主张**控制货币供给**（单一规则）
- 引入预期，提出**附加预期的菲利普斯曲线**
- 长期菲利普斯曲线垂直：扩张政策长期只造成通胀

#### **4. 供给学派**
- "打回萨伊那里去"
- 主张**减税**刺激供给
- 里根减税实践

#### **5. 理性预期学派（卢卡斯）**
- **卢卡斯批判**：凯恩斯模型忽略公众理性预期
- 公众预期使AS曲线移动，凯恩斯政策只会造成通胀

#### **6. 博弈论的兴起**
- 理性预期理论兴起后，经济学家开始注重预期在政策制定中的作用
- 博弈论开始应用于经济政策分析

#### **7. 新凯恩斯学派**
- 吸收预期概念，但保留政府干预思想

### **八、相机抉择 vs 单一规则**

这是凯恩斯学派与货币学派最核心的政策分歧：

| | 凯恩斯学派 | 货币学派 |
|---|---|---|
| 政策主张 | **相机抉择** | **单一规则** |
| 含义 | 根据经济形势灵活改变政策 | 年初制定政策，全年不变 |
| 优点 | 危机时刻可快速应对（如1929大危机） | 保持政策连续性和可信度 |
| 缺点 | 可能短视，只顾眼前 | 无法应对突发重大危机 |

视频最后引用了凯恩斯的名言——**"从长期来看，我们都死了"**——来解释相机抉择的合理性：眼前危机必须先解决，保住命再调理身体。但也引用了熊彼特的话提醒：短期决策必须考虑对长期的效果，否则就是不负责任——既要应对眼前危机，也要考虑长远可持续发展。
