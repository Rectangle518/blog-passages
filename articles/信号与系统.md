
## 第一章

1. 实数的模可以理解为实数的绝对值，复数的模为复数的模长，即复数的模是复数到原点的距离。

$$|e^{j(2t)}|^2 = 1$$

$$|e^{2t}|^2 = e^{4t}$$

$$|cos(t)|^2 = cos^2(t)$$

2. 例：求 $e^{j \frac{4 \pi}{7}n} $的周期性。

> 若 $e^{jwn} $为周期为 $N$ 的周期信号，则 $e^{jw(n+N)} = e^{jwn} $，则 $e^{jwN} = 1$，则 $wN = 2k \pi$，则 $\frac{w}{2 \pi} = \frac{k}{N}$ 是有理数，可得 $N = \frac{2k \pi}{w} $，需要保证 $N$ 是整数。

这里 $w = \frac{4 \pi}{7}$，满足 $\frac{w}{2 \pi}$ 是有理数，则该信号是周期的。

$N = \frac{2k \pi}{w} = k \frac{7}{2}$，至少取 $k = 2$ 使得 N 为整数，则 $N = 2$，即周期为 2。

如果已知周期 为 $N$，则 $w_0 = \frac{2 \pi}{N}$。

## 第二章

1. 单位冲激函数和其他信号做卷积运算的一些规律和性质

$$x(t) * \delta(t) = x(t)$$

$$x(t) * \delta(t-t_0) = x(t-t_0)$$

$$x(t) * \delta^{(k)}(t-t_0) = x^{(k)}(t-t_0)$$

$$x(t) * u(t) = \int_{-\infty}^{t}x(\tau)d\tau$$

2. 卷积运算满足交换律、分配律、结合律。

3. 假设一个系统的单位冲激响应是 $h(t)$，输入信号是 $x(t)$，则输出信号是二者的卷积 $y(t) = x(t) * h(t)$。


4. 如果一个线性时不变系统是因果的，则需要满足以下条件。

$$h(t) = 0, t < 0$$

$$h[n] = 0, n < 0$$

> 一个**线性**系统的因果性就等价于**初始松弛**条件。

5. 如果一个线性时不变系统是稳定的，则需要满足以下条件。

- 离散：单位冲激函数绝对可和。
- 连续：单位冲激函数绝对可积。

## 第三章

1. 注意一个易错点，欧拉公式的正弦部分前面有个 $j$ 。

$$e^{j \theta} = cos(\theta) + j sin(\theta)$$

$$sin(\theta) = \frac{e^{j \theta} - e^{-j \theta}}{2j}$$

2. 一个系统的频率响应：当你向系统输入一个单一频率的正弦波（或复指数信号）时，系统输出信号的幅度和相位会如何随输入频率的变化而变化。

$$H(jw) = \int_{-\infty}^{\infty}h(t)e^{-jwt}dt$$

$$H(e^{jw}) = \sum_{n=-\infty}^{\infty}h[n]e^{-jwn}$$

> 线性时不变系统只会改变输入信号的幅度和相位，不会改变输入信号的频率。

> $H(jw)$ 的模称为幅频响应，它的相角称为相频响应。

> 复指数函数是线性系统的“特征函数”。

如果输入信号是 $x(t) = e^{jw_0t}$，则输出信号是 $y(t) = H(jw_0)e^{jw_0t}$。

如果输入信号是 $$x(t) = \sum_{k=-\infty}^{\infty}a_k e^{jkw_0t}$$ 则输出信号是 $$y(t) = \sum_{k=-\infty}^{\infty}a_k H(jkw_0)e^{jkw_0t}$$

3. 一个式子：$e^{-jk \pi} = (-1)^k$。

## 第四章

1. **傅里叶变换对**。

$$X(jw) = \int_{-\infty}^{\infty}x(t)e^{-jwt}dt$$

$$x(t) = \frac{1}{2 \pi} \int_{-\infty}^{\infty}X(jw)e^{jwt}dw$$

推导过程如下。

由 $$x(t) = \sum_{k=- \infty}^{\infty}a_k e^{jkw_0t} = \frac{1}{T} \sum_{k=- \infty}^{\infty}Ta_k e^{jkw_0t}$$

$$a_k = \frac{1}{T} \int_T x(t)e^{-jkw_0t}dt$$

$$Ta_k = \int_T x(t)e^{-jkw_0t}dt$$

令 $T \rightarrow \infty$，则 $\frac{1}{T} \rightarrow df = \frac{1}{2 \pi} dw$，$kw_0 \rightarrow w$，$Ta_k \rightarrow X(jw)$，$\sum \rightarrow \int$。

2. **周期信号**的傅里叶变换。

$$e^{jw_0t} \leftrightarrow 2\pi \delta(w-w_0)$$

推导过程如下。

$$x(t) = \frac{1}{2 \pi} \int_{-\infty}^{\infty}2\pi \delta(w-w_0)e^{jwt}dw = e^{jw_0t}$$

对偶之后也类似。

$$\delta(t-t_0) \leftrightarrow e^{-jwt_0}$$

$$X(jw) = \int_{-\infty}^{\infty} \delta(t-t_0)e^{-jwt}dt = e^{-jwt_0}$$

3. 对于复数，共轭运算与复数乘法运算是可交换的。

5. 若一个信号在时域是周期的，那么它在频域就是离散的。若一个信号在频域是周期的，那么它在时域就是离散的。

6. 在时域相乘，在频域是卷积。在频域相乘，在时域是卷积。

$$h(t) * x(t) \leftrightarrow H(jw)X(jw)$$

$$h(t)x(t) \leftrightarrow \frac{1}{2 \pi}H(jw) * X(jw)$$

> 在时域相乘是调制，在频域相乘是滤波。

7. 帕斯瓦尔定理。

$$\int_{-\infty}^{\infty}|x(t)|^2dt = \frac{1}{2 \pi} \int_{-\infty}^{\infty}|X(jw)|^2dw$$
