
## 第一章

1. 实数的模可以理解为实数的绝对值，复数的模为复数的模长，即复数的模是复数到原点的距离。

$$|e^{j(2t)}|^2 = 1$$

$$|e^{2t}|^2 = e^{4t}$$

$$|cos(t)|^2 = cos^2(t)$$

2. 例：求 $e^{j \frac{4 \pi}{7}n} $的周期性。

> 若 $e^{jwn} $为周期为 $N$ 的周期信号，则 $e^{jw(n+N)} = e^{jwn} $，则 $e^{jwN} = 1$，则 $wN = 2k \pi$，则 $\frac{w}{2 \pi} = \frac{k}{N}$ 是有理数，可得 $N = \frac{2k \pi}{w} $，需要保证 $N$ 是整数。

这里 $w = \frac{4 \pi}{7}$，满足 $\frac{w}{2 \pi}$ 是有理数，则该信号是周期的。

$N = \frac{2k \pi}{w} = k \frac{7}{2}$，至少取 $k = 2$ 使得 N 为整数，则 $N = 2$，即周期为 2。

如果已知周期 为 $N$，则 $w_0 = \frac{2 \pi}{N}$。

## 第二章

1. 单位冲激函数和其他信号做卷积运算的一些规律和性质

$$x(t) * \delta(t) = x(t)$$

$$x(t) * \delta(t-t_0) = x(t-t_0)$$

$$x(t) * \delta^{(k)}(t-t_0) = x^{(k)}(t-t_0)$$

$$x(t) * u(t) = \int_{-\infty}^{t}x(\tau)d\tau$$

2. 卷积运算满足交换律、分配律、结合律。

3. 假设一个系统的单位冲激响应是 $h(t)$，输入信号是 $x(t)$，则输出信号是二者的卷积 $y(t) = x(t) * h(t)$。


4. 如果一个线性时不变系统是因果的，则需要满足以下条件。

$$h(t) = 0, t < 0$$

$$h[n] = 0, n < 0$$

> 一个**线性**系统的因果性就等价于**初始松弛**条件。

5. 如果一个线性时不变系统是稳定的，则需要满足以下条件。

- 离散：单位冲激函数绝对可和。
- 连续：单位冲激函数绝对可积。

## 第三章

1. 注意一个易错点，欧拉公式的正弦部分前面有个 $j$ 。

$$e^{j \theta} = cos(\theta) + j sin(\theta)$$

$$sin(\theta) = \frac{e^{j \theta} - e^{-j \theta}}{2j}$$

2. 一个系统的频率响应：当你向系统输入一个单一频率的正弦波（或复指数信号）时，系统输出信号的幅度和相位会如何随输入频率的变化而变化。

$$H(jw) = \int_{-\infty}^{\infty}h(t)e^{-jwt}dt$$

$$H(e^{jw}) = \sum_{n=-\infty}^{\infty}h[n]e^{-jwn}$$

> 线性时不变系统只会改变输入信号的幅度和相位，不会改变输入信号的频率。

> $H(jw)$ 的模称为幅频响应，它的相角称为相频响应。

> 复指数函数是线性系统的“特征函数”。

如果输入信号是 $x(t) = e^{jw_0t}$，则输出信号是 $y(t) = H(jw_0)e^{jw_0t}$。

如果输入信号是 $$x(t) = \sum_{k=-\infty}^{\infty}a_k e^{jkw_0t}$$ 则输出信号是 $$y(t) = \sum_{k=-\infty}^{\infty}a_k H(jkw_0)e^{jkw_0t}$$

3. 一个式子：$e^{-jk \pi} = (-1)^k$。

## 第四章

1. **连续时间傅里叶变换对**。

$$X(jw) = \int_{-\infty}^{\infty}x(t)e^{-jwt}dt$$

$$x(t) = \frac{1}{2 \pi} \int_{-\infty}^{\infty}X(jw)e^{jwt}dw$$

推导过程如下。

由 $$x(t) = \sum_{k=- \infty}^{\infty}a_k e^{jkw_0t} = \frac{1}{T} \sum_{k=- \infty}^{\infty}Ta_k e^{jkw_0t}$$

$$a_k = \frac{1}{T} \int_T x(t)e^{-jkw_0t}dt$$

$$Ta_k = \int_T x(t)e^{-jkw_0t}dt$$

令 $T \rightarrow \infty$，则 $\frac{1}{T} \rightarrow df = \frac{1}{2 \pi} dw$，$kw_0 \rightarrow w$，$Ta_k \rightarrow X(jw)$，$\sum \rightarrow \int$。

2. **周期信号**的傅里叶变换。

$$e^{jw_0t} \leftrightarrow 2\pi \delta(w-w_0)$$

推导过程如下。

$$x(t) = \frac{1}{2 \pi} \int_{-\infty}^{\infty}2\pi \delta(w-w_0)e^{jwt}dw = e^{jw_0t}$$

对偶之后也类似。

$$\delta(t-t_0) \leftrightarrow e^{-jwt_0}$$

$$X(jw) = \int_{-\infty}^{\infty} \delta(t-t_0)e^{-jwt}dt = e^{-jwt_0}$$

3. 对于复数，共轭运算与复数乘法运算是可交换的。

5. 若一个信号在时域是周期的，那么它在频域就是离散的。若一个信号在频域是周期的，那么它在时域就是离散的。

6. 在时域相乘，在频域是卷积。在频域相乘，在时域是卷积。

$$h(t) * x(t) \leftrightarrow H(jw)X(jw)$$

$$h(t)x(t) \leftrightarrow \frac{1}{2 \pi}H(jw) * X(jw)$$

> 在时域相乘是调制，在频域相乘是滤波。

7. 帕斯瓦尔定理。

$$\int_{-\infty}^{\infty}|x(t)|^2dt = \frac{1}{2 \pi} \int_{-\infty}^{\infty}|X(jw)|^2dw$$

## 第五章

1. **离散时间傅里叶变换对。**

$$x[n] = \frac{1}{2 \pi} \int_{2 \pi} X(e^{jw})e^{jwn}dw$$

$$X(e^{jw}) = \sum_{n=-\infty}^{\infty}x[n]e^{-jwn}$$

推导过程如下。

由（这里的 k=N 表示 k=\<N\>）

$$ \tilde{x}[n] = \sum_{k=N} a_k e^{jkw_0n}$$

$$ a_k = \frac{1}{N} \sum_{n=N} \tilde{x}[n]e^{-jkw_0n}$$

其中 $x[n]$ 是原本的非周期离散时间信号，在 $-N_1 \leq n \leq N_2 $ 的范围之外都有 $x[n] = 0$。

而 $\tilde{x}[n]$ 是对其进行周期延拓后的周期为 $N$ 的周期信号。

在一个周期内，即 $-N_1 \leq n \leq N_2 $ 的范围内有 $x[n] = \tilde{x}[n]$，因此在 $a_k$ 的表达式中可以进行替换。

$$a_k = \frac{1}{N} \sum_{n=-N_1}^{N_2} x[n]e^{-jkw_0n} = \frac{1}{N} \sum_{n=-\infty}^{\infty} x[n]e^{-jkw_0n}$$

现在定义如下函数。

$$X(e^{jw}) = \sum_{n=-\infty}^{\infty}x[n] e^{-jwn}$$

故有

$$a_k = \frac{1}{N} X(e^{jkw_0})$$

$$ \tilde{x}[n] = \sum_{k=N}a_k e^{jkw_0n} = \sum_{k=N} \frac{1}{N} X(e^{jkw_0}) e^{jkw_0n} $$

令 $N \rightarrow \infty$，则 $kw_0 \rightarrow w$，$w_0 \rightarrow dw$，$\frac{1}{N} \rightarrow \frac{1}{2 \pi} dw$，$\sum \rightarrow \int$。

因为原本的求和是在 $N$ 个宽度为 $w_0 = \frac{2 \pi}{N}$ 上进行的，因此总的积分区间是一个 $2 \pi$ 的宽度。

$$x[n] = \frac{1}{2 \pi} \int_{2 \pi} X(e^{jw})e^{jwn}dw$$

2. **周期信号的傅里叶变换。**

$$e^{jw_0n} \leftrightarrow \sum_{l = -\infty}^{\infty} 2\pi \delta(w-w_0-2 \pi l)$$

推导过程如下。

$$x[n] = \frac{1}{2 \pi} \int_{2 \pi} \sum_{l = -\infty}^{\infty} 2\pi \delta(w-w_0-2 \pi l)e^{jwn}dw = e^{j(w_0+2 \pi r)n} = e^{jw_0n}$$

考虑一个周期序列。

$$x[n] = \sum_{k=N} a_k e^{jkw_0n}$$

$$X(e^{jw}) = \sum_{k=- \infty}^{\infty}2 \pi a_k \delta(w-kw_0)$$

3. **共轭与共轭对称性质。**

$$x[n] \leftrightarrow X(e^{jw})$$

$$x^*[n] \leftrightarrow X^*(e^{-jw})$$

若 $x[n]$ 是实值序列，则 $x[n] = x^*[n]$，则 $X(e^{jw}) = X^*(e^{-jw})$。

进一步可得如下结论。

$$Ev\\{x[n]\\} \leftrightarrow Re\\{X(e^{jw})\\}$$

$$Od\\{x[n]\\} \leftrightarrow jIm\\{X(e^{jw})\\}$$

4. **帕斯瓦尔定理。**

$$\sum_{n=-\infty}^{\infty}|x[n]|^2 = \frac{1}{2 \pi} \int_{2 \pi} |X(e^{jw})|^2dw$$

## 第六章

1. 全通系统：一个系统的频率响应在所有频率的模都为 1。

2. 从傅里叶变换公式来看，$X(jw)$ 本身就可以看作信号 $X(t)$ 的一种分解，即把信号 $x(t)$ 分解为成不同频率的复指数之“和”。

3. 如果相位函数不同，即使模函数相同，最后的傅里叶变换也可能非常不同。

4. 线性相位。

当相移是 $w$ 的线性函数时，例如一个连续时间线性时不变系统的频率响应为：

$$H(jw) = e^{-jwt_0}$$

则该系统具有单位增益和线性相位：

$$|H(jw)| = 1$$

$$\angle H(jw) = -w t_0$$

而由第四章的内容可知，具有这种频率响应特性的系统，其输出信号就是输入信号的时移：

$$y(t) = x(t-t_0)$$

> 在离散时间情况下，若w的斜率是整数，则有同样的性质。

5. 群延迟。

可以简单理解为：一群频率相近的信号所具有的近似相同的时延。

$$\tau(w) = -\frac{d}{dw} \angle H(jw)$$

6. 伯德图。

采用的对数标尺是以 $20 log_{10}$ 为单位的，称为分贝。

0 dB 对应于频率响应的模为 1；而 20 dB 对应于频率响应的模为 10；记住 6 dB 对应于频率响应的模为 2。

连续时间下，$20 log_{10} |H(jw)|$ 和 $\angle H(jw)$ 对于 $log_{10} (w)$ 的图像称为伯德图。

离散时间下，采用 $20 log_{10} |H(e^{jw})|$ 和 $\angle H(e^{jw})$ 对于 $w$ 的图像。

7. 理想低通滤波器。

当 $|w| \leq w_c$ 时，$H(jw) = 1$，其余为 $0$。

则其对应得傅里叶逆变换为：

$$H(jw) \leftrightarrow \frac{sin(w_ct)}{\pi t}$$

## 第七章

1. 如果一个信号是带限的（若不带限，则一定会混叠），并且它的样本取得足够密，这些样本值就能唯一地确定这个信号。

2. 冲激串采样。

用一个周期冲激串去对一个连续时间信号进行采样，这个周期冲激串 $p(t)$ 称为采样函数，其周期称为采样周期，其频率称为采样频率。

$$p(t) = \sum_{k=-\infty}^{\infty} \delta(t-kT)$$

在时域中，$x_p(t) = x(t)p(t)$，由 $x(t) \delta(t-t_0) = x(t_0) \delta(t-t_0)$ ，可得：

$$x_p(t) = \sum_{k=-\infty}^{\infty} x(kT) \delta(t-kT)$$

现在求 $x_p(t)$ 的傅里叶变换。

$$P(jw) = \frac{2 \pi}{T} \sum_{k=-\infty}^{\infty} \delta(w-kw_s)$$

由 $X_p(jw) = \frac{1}{2 \pi} X(jw) * P(jw)$，且 $X(jw) * \delta(w-w_0) = X(j(w-w_0))$，可得：

$$ X_p(jw) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X(j(w-kw_s) $$

也就是说，$X_p(jw)$ 是频率为 $w_s$ 的周期函数，它由一组移位的 $X(jw)$ 的叠加组成，幅度上有一个比例因子 $\frac{1}{T}$。

> 若 $w_m > w_s - w_m$，即 $w_s < 2 w_m$，则发生混叠，不能恢复。
> 其中 $w_m$ 是 $x(t)$ 的频率限，$w_s$ 是采样频率。

> 采样定理明确要求采样频率 $w_s$ 必须大于信号的最高频率的两倍，而不是大于等于。

3. 欠采样的效果：混叠。

出现混叠后，对于频率为 $w_0$ 的信号，$w_s / 2 < w_0 < w_s$，它会被混叠成频率为 $w_0 - w_s$ 的信号，注意相位倒置。

4. 理想情况下，我们用单位冲激采样，之后用理想低通滤波器进行恢复；而在实际情况下，我们没有办法用单位冲激来采样，只能用零阶保持的方法来采样，现在正在求的就是这种采样之后的恢复方式。由于零阶保持采样等价于单位冲激采样后再通过一个零阶保持系统，于是我们只需要让零阶保持系统复合补偿滤波器之后等于理想低通滤波器即可。
