# Yuyang's Blog

欢迎来到我的个人博客仓库！

我是中山大学计算机学院2024级的本科生，这里记录了我的一些学习和思考。

## 📚 项目结构

```
blog_passages/
├── articles/              # 博客文章目录
├── deleted_articles/      # 已删除的博客文章
├── images/                # 图片资源目录
├── articles-index.json    # 文章索引配置文件
├── deleted.json           # 已删除文章记录
├── index.html             # 博客首页
├── index_old.html         # 博客首页（旧版）
├── logs.txt               # 操作日志文件
├── slides.html            # 工具：Markdown Slides
└── README                 # 项目说明文件
```
